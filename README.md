# Number Garden（数字花园）

面向 10-12 岁小学生的互动式数学认知训练 MVP。它强调数字关系、位值结构、进位/退位中的单位转换，而不是刷题速度。

## 功能

- 数字探索：输入数字后生成关系树，点击枝叶查看解释。
- 进位实验室：用“十”和“一”的积木展示 `27 + 18` 中 `10个一 = 1个十`。
- 退位实验室：用单位转换解释 `42 - 18`，强调退位不是借东西。
- 今日挑战：鼓励孩子发现多个等价关系，并把探索记录保存在 LocalStorage。

## 运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```
